# Седьмая — установка и запуск на новом компьютере

Игра к хакатону: 2D-стратегия о летающей башне над Мглой. Phaser 4 + TypeScript + Vite.
Репозиторий: https://github.com/SurveDern1/hakaton, основная ветка `main`.
Сайт с последней версией: https://survedern1.github.io/hakaton/ (макеты — https://survedern1.github.io/hakaton/design/).

## 1. Что должно стоять

| Программа | Версия | Проверка |
|---|---|---|
| Git | любая свежая | `git --version` |
| Node.js | **22 или новее** (есть npm) | `node -v` |
| Claude Code | любая | `claude --version` |

Node.js, если его нет или версия ниже 22: https://nodejs.org (LTS) или `winget install OpenJS.NodeJS.LTS`.
После установки откройте новый терминал.

## 2. Получить код

Если папка с репозиторием уже есть:

```bash
cd путь/к/hakaton
git checkout main
git pull
```

Если папки нет:

```bash
git clone https://github.com/SurveDern1/hakaton.git
cd hakaton
```

Чтобы пушить, нужен доступ на запись: владелец добавляет ваш GitHub-аккаунт в
Settings → Collaborators. Без доступа можно сделать форк и присылать пулл-реквесты.

## 3. Зависимости

```bash
npm ci
```

`npm ci` ставит ровно те версии, что записаны в `package-lock.json`. Если команда ругается,
подойдёт и `npm install`.

## 4. Запуск и проверка

| Команда | Что делает |
|---|---|
| `npm run dev` | Игра на http://localhost:5173, перезагружается при правках |
| `npm run check` | Типы, линтер и формат, тесты, проверка данных и макетов — **должна проходить перед каждым коммитом** |
| `npm run format` | Исправить формат и порядок импортов |
| `npm run build` | Сборка в `dist/` |
| `npm run design` | Макеты для дизайнеров в браузере |
| `npm run icons` | Перерисовать иконки в `public/` после правки `tools/make-icons.js` (нужен Chrome) |

Отладка в браузере: `?preset=good` — только башня из макета, `?event=d02_raft` — сразу окно события.
В консоли браузера доступен `window.sedmaya` (`store`, `loop`, `events`, `tower`, `sound`).

Звук включается после первого клика или касания (так требуют браузеры, особенно на телефоне).
Выключить — пункт «Звук» в меню игры, кнопка ♪ в углу на стартовом экране или клавиша M; выбор запоминается.

Игра сделана под телефон в портрете. На компьютере она показывается колонкой 9:16 по центру; чтобы
увидеть как на телефоне, включите в DevTools режим устройства (Ctrl+Shift+M, например 390×844).
С телефона в той же сети: `npm run dev -- --host` и адрес `http://<IP компьютера>:5173`.

Если сразу после установки `npm run check` проходит, а `npm run dev` открывает стартовый экран
«Седьмая» — всё готово.

## 5. Работа с Claude Code

Запускайте `claude` в папке репозитория и первым сообщением пишите:

> Прочитай AGENTS.md, TZ-sedmaya.md и STORY-sedmaya.md, потом …

Главное из правил проекта (подробно — в `AGENTS.md`):

- `src/core` — чистая логика без Phaser и DOM, с тестами; экран только показывает состояние.
- Все числа — в `data/balance.json`, в коде их нет. Случайность — только через `src/core/rng.ts`.
- После правки `data/` запускать `node tools/check-data.js`.
- Коммиты на русском, без упоминаний ИИ и приписок `Co-Authored-By`.

## 6. Как работать вдвоём

- Перед началом работы: `git pull`.
- Каждая задача — в своей ветке:
  ```bash
  git checkout -b имя-задачи
  ```
- Готово → `npm run check` → влить в `main` и запушить. **Пуш в `main` сразу выкладывает сайт**
  (GitHub Actions: проверка, сборка, GitHub Pages), поэтому в `main` идёт только проверенное.
- Договоритесь, кто какие файлы правит (например, один — `src/ui`, другой — `src/core` и `data/`),
  тогда конфликтов почти не будет.

## 7. Если что-то не так

| Проблема | Что делать |
|---|---|
| `npm` не найден или старый Node | Поставить Node 22+, открыть новый терминал |
| В PowerShell «выполнение сценариев отключено» | `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` или запускать из Git Bash / cmd |
| Порт 5173 занят | `npx vite --port 5180` |
| `git pull` ругается на локальные изменения | `git status`, закоммитить или убрать свои правки, потом снова `git pull` |
| Странные ошибки после pull | Заново `npm ci` — могли поменяться зависимости |
